# 隐私说明（首版）

> 适用版本：0.1.x。本文件随安装包发布，说明「时光」收集什么、存在哪里、何时离开本机以及如何删除。

## 1. 默认只在本机处理

- 采集、加密、检索、日报、语音识别与语音合成全部在本机完成。
- 默认不启用公网模型；未配置 `models.json` 时不向任何远程端点发送数据。
- 本地 MCP 默认关闭；启用后只监听 `127.0.0.1`，需要本地令牌，且只暴露四个只读工具。

## 2. 收集的内容

| 类别 | 内容 | 触发条件 |
|---|---|---|
| 窗口活动 | 前台应用名、窗口标题、开始/结束时间 | 采集开启时 |
| 文本 | 可访问性树文本或 OCR 结果、摘要 | 采集与文本提取开启时 |
| 屏幕快照 | 窗口/屏幕截图（AES-GCM 加密） | 采集开启且平台支持时 |
| 文件活动 | 白名单目录内的文件变更元数据 | 用户显式配置目录后 |
| 音频 | 麦克风音频 | 语音会话显式启用并唤醒时；命令音频默认仅驻留内存 |
| 语音日志 | 唤醒词、识别文本、意图、参数（加密数据库） | 语音命令执行时；不含音频 |
| 日报与问答 | 由本地模型生成的 Markdown、统计 JSON、证据引用 | 用户生成时 |

明确不收集：键盘按键、剪贴板、密码框内容、全盘文件内容、浏览器历史数据库。

## 3. 存储与加密

- 结构化数据：SQLite3MC 页级加密（AES-256），密钥由 Windows DPAPI / macOS Keychain / Linux libsecret 保护。
- 媒体：AES-256-GCM 逐文件加密，引用计数 + 保留期自动安全擦除。
- 模型端点密钥：AES-GCM 加密的 `secrets/model-secrets.enc`，包装密钥在系统密钥库。
- 本地 MCP 令牌：AES-GCM 加密的 `security/local-mcp-token.enc`。
- 日志：有界滚动 JSONL，写入前强制脱敏（密钥、完整路径、URL 查询串、正文）。
- 数据目录：`%LOCALAPPDATA%\AiAssistant`、`~/Library/Application Support/AiAssistant` 或 `~/.local/share/AiAssistant`，可用 `AIASSISTANT_DATA_DIRECTORY` 覆盖。

## 4. 数据何时离开本机

只有在同时满足以下条件时，事件摘要才会发送到已配置的模型端点：

1. `models.json` 配置了对应档位（本机 / 企业内网 / 公网）；
2. 企业策略允许该档位（公网还需运行时显式同意）；
3. 请求通过「最小化 → 脱敏 → 残留检测」三道闸，敏感残留会被阻断而不是放行。

内网档故障时可回退本机档；不会静默升级到公网。所有模型调用写入无正文审计（时间、用途、档位、字符数、耗时、是否脱敏）。

## 5. 用户控制

- 暂停采集：立即阻断入口并清空待处理队列，恢复后不补采暂停期间活动。
- 黑名单：应用名/窗口标题关键字，内置密码管理器与隐私浏览规则。
- 数据删除：「数据与导出」页可删除指定日期或清空全部本地数据（事件、媒体、日报、任务、语音日志、向量索引）。
- 导出：日报 Markdown、问答证据、周报（Markdown + stats JSON）、脱敏诊断预览；全部在本机生成。
- 语音：默认关闭；唤醒窗口 8 秒；退出应用需二次确认。

## 6. 保留期

- 结构化事件：长期保留，直到用户删除。
- 加密媒体：按写入时的保留期自动清理；清理后事件仍可查看，问答只会说明「原始媒体已清理」。
- 日志：有界滚动，超出上限自动截断最旧记录。

## 7. 卸载与残留

自包含 zip 与当前 MSIX 卸载都不会自动删除 `%LOCALAPPDATA%\AiAssistant` 与系统密钥库条目，避免误删；MSIX 清单已关闭 AppData 虚拟化，数据不在包容器内。旧版 MSIX（未关闭虚拟化）卸载会删除包容器数据，请先导出/备份。彻底清除步骤见 `UPGRADE-AND-UNINSTALL.md`。

## 8. 联系方式

安全问题请通过仓库 Issue 私下报告，不要在公开 Issue 中粘贴日志或数据文件。
