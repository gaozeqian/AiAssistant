| 安装包卸载不删除数据 | 需手动清理 | 见 `UPGRADE-AND-UNINSTALL.md` |

## 安全边界

- 加密保护的是「磁盘上的数据」；应用运行期间内存中的明文由操作系统隔离与用户账户权限保护。
- 密钥库条目被删除后，历史数据库无法解密（故障注入测试覆盖该路径，会给出可诊断错误而不是静默损坏）。
- MCP 只读端点不返回媒体字节，但会返回事件摘要；启用前请确认本机账户可信。
