# ADR-0010：任务持久幂等、启动补偿与版本化日报策略

- **状态**：已采纳 (Accepted)
- **日期**：2026-11-20
- **适用版本**：0.1.x
- **维护触发条件**：决策被取代或修订时新增 ADR，本文件结论不改
- **阶段**：S0 / S1 / S5

## 背景

桌面设备随时可能休眠、关机或强制退出，单纯依赖 23:30 内存定时器会导致日报丢失；同时用户手动重生成与启动自动补偿具有不同的覆盖语义。

## 决策

1. 所有日报生成请求统一写入 SQLite 持久表 `report_jobs`，由单消费者 Worker 串行执行，应用重启后可将中断的 `Running` 任务安全恢复至待重试状态。
2. 区分触发源幂等语义：
   - **启动补偿 / 定时触发**：若目标 `local_date` 已存在有效日报，直接幂等标记完成，不重复消耗算力；
   - **手动强制重生成**：在同一 `local_date` 下递增 `version` 生成新版本日报，保留历史版本可追溯，查询默认取最大 `version`。
3. 失败采用有界指数退避（最多 3 次），超出上限标记 `Failed` 并保留诊断摘要，绝不写入看似成功的空日报。

## 后果

- 任意关机、崩溃或模型离线后均可自动恢复或明确诊断，数据演进清晰可追溯。
